# Sowmya - Personal Portfolio Website

A personal portfolio website built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS**. Designed with a dark, tech-oriented aesthetic and light blue accents.

---

## 🚀 Features

- **Dark & Techy Aesthetic:** Deep slate/zinc theme with light blue glowing highlights and subtle grid patterns.
- **Responsive Layout:** Optimized for mobile phones, tablets, and desktop displays.
- **Smooth Navigation:** Smooth scrolling navigation bar with an interactive mobile menu.
- **Section Order:**
  1. **Navbar** (`app/components/Navbar.tsx`)
  2. **Hero** (`app/components/Hero.tsx`)
  3. **About** (`app/components/About.tsx`)
  4. **Projects** (`app/components/Projects.tsx` with reusable `ProjectCard.tsx`)
  5. **Contact** (`app/components/Contact.tsx`)
  6. **Footer** (`app/components/Footer.tsx`)

---

## 🛠️ Getting Started

### 1. Install Dependencies
Open your terminal in this directory and run:
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

### 3. Open in Browser
Visit [http://localhost:3000](http://localhost:3000) to view your portfolio!
